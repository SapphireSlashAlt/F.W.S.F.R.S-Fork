# Contributing Rules
If you want to contribute, you have to follow these rules: 

## For All
* Use good grammar.
* Follow every rule stated in the [code of conduct].(https://github.com/SapphireSlash/F.W.S.F.R.S/blob/main/CODE_OF_CONDUCT.md)

## Issues
* If you've found something in the documentation content, or something else that should be updated, search the open issues to see if someone else has reported the same thing. If it's something new, open an issue using a template.

## Pull Requests
* Check the preview of anything you have changed. Checking the preview will help you identify problems such as typos and incorrect things that should be fixed.
* If there are any failing checks in your pull request, troubleshoot them until they're all passing.
